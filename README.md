# KaamSathi Voice Guide

**Proof the worker understood, not proof the notice was posted.**

A voice-first, multilingual safety companion for migrant factory workers. Built as a prototype for the TCS iON AI Hackathon, challenge *Factory Worker's AI Companion* (theme: Inclusive workforce).

## The problem

Industrial areas employ many migrant workers from other states. Language barriers and limited digital skills make it hard for them to understand safety rules, check shift schedules and file complaints. Factories usually keep records that a notice was *posted*. They rarely check that the worker *understood* it.

## What KaamSathi does

1. **Speak in your language.** The worker picks Hindi, Bengali, Odia, Tamil or English and asks by voice, tap or typing. Safety rules come back as big icons and short, simple sentences.
2. **Explain it back.** After each rule the worker answers a short teach-back question in their own words (voice, typed or tap). Gemini judges the meaning, not the exact words.
3. **Supervisors see where it fails.** A dashboard shows which rule is misunderstood in which language, which workers need retraining, and the complaints workers filed.

Also included: shift and leave lookup, and a voice complaint box that translates and summarises complaints for HR.

## Features

- Five languages with correct scripts: हिन्दी, বাংলা, ଓଡ଼ିଆ, தமிழ், English
- Teach-back understanding check with a fixed fallback when the AI is unavailable
- Supervisor dashboard: confusion by rule and language, retraining list, complaints
- Works with **no API key** (demo mode). Uses Gemini only when a key is set on the server
- Safety text is curated, not AI-generated
- No dependencies, no build step, runs in a phone browser with no login

## Quick start

Needs Node 18 or newer.

```bash
cd kaamsathi
node server.js
```

Open http://localhost:3000. The supervisor dashboard is at http://localhost:3000/#/dashboard.

### Optional: live Gemini

The key stays on the server and is never sent to the browser.

```powershell
$env:GEMINI_API_KEY = "your-key"
$env:GEMINI_MODEL = "gemini-3.5-flash-lite"   # optional, change if your key uses another model
node server.js
```

If Gemini fails or takes longer than 8 seconds, the app falls back to demo mode and the badge shows **AI offline**.

Do not commit your key. Set it only as an environment variable.

## Using it on a phone

The microphone needs HTTPS or `localhost`. Typing and tap answers always work. See [`kaamsathi/README.md`](kaamsathi/README.md) for four ways to reach the app from a phone.

## Limits, stated plainly

- It is a prototype. The dashboard's 200 sessions and 3 complaints are **simulated sample data**.
- Translations were written by an AI and have **not** been reviewed by native speakers.
- Odia voice output is often missing on Android phones. The app shows a badge and works as text and taps.
- Not tested with real workers or on a physical phone. Browser speech recognition varies by device and language.
- Anyone with the server URL can post log rows. The reset action is protected only by a local-origin check or an admin token.

## Root cause it targets

Factories and software providers optimise communication for compliance records and an assumed "standard worker", not for real comprehension. KaamSathi measures understanding and gives supervisors the evidence to improve how they explain rules.
